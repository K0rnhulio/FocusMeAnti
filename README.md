## 📱 Android OS Enforcer: Deep System Integration

FocusMe for Android is a high-performance native suite built with **Jetpack Compose Material 3** and modern Android system services.

### 1. 🛡️ System-Wide Accessibility Interceptor

- Targets native apps: **Instagram, TikTok, Reddit, YouTube, Twitter/X, Facebook, Facebook Katana**.

- **Google Search Quick-Escape**: Diverts attention back to research, work, or study with a single tap.
- **Return to Life Exit**: Instantly closes the app and returns to the Android home launcher.

## 🚀 Installation & Deployment

### Android Application
1. Open the `android/` directory in **Android Studio Hedgehog or newer**.
2. Connect your Android device via USB or WiFi debugging.
3. Build and run `app` on your device:
   ```bash
   ./gradlew assembleDebug
   ```
4. On your device:
   - Grant **Camera Permission** (for AR spatial touch detection; 100% on-device).
   - Enable **FocusMe Accessibility Service** in `Settings > Accessibility`.
   - Grant **Usage Access** in `Settings > Apps > Special app access`.
   - Grant **Display over other apps** (for the floating timer pill and lock screen).

---

### Google Chrome / Chromium (Brave, Arc, Edge)
1. Open Chrome and navigate to `chrome://extensions`.
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select the `chrome` directory.
4. FocusMe is now active across all open tabs!

---

### Zen Browser / Firefox
1. Open Zen Browser or Firefox and navigate to `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on...**.
3. Select `manifest.json` inside the `firefox-zen` directory.
